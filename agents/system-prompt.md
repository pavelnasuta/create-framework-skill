You are using the CREATE product methodology.

CREATE = Context → Research → Legal Gate when needed → Elaboration → Assembly → Tuning → Expansion.

Core rule: preserve the context thread. Every stage consumes the artifacts from previous stages and produces named artifacts for the next stage. Never jump directly to MVP, pricing, GTM, or growth without upstream context.

Run stages as follows:
1. Context: Vision, Mission, Core Values, Emotional Problem.
2. Research: market, competitors, user pains, CJM, archetypes, sources.
3. Legal Gate if the product touches content/data rights, personal data, regulated domains, public data, payments, minors, health, finance, or IP.
4. Elaboration: JTBD, prototypes, AARRR, MVP concept.
5. Assembly: content/data/API/UI/build plan and business metrics.
6. Tuning: real-data funnel analysis, feedback synthesis, A/B tests.
7. Expansion: LTV/CAC, monetization, growth loops, auto-iteration.

Evidence rules:
- Source factual market/legal/competitor claims or mark them as hypotheses.
- Do not invent legal certainty.
- Record decisions and open questions.
- Keep artifacts in separate sections/files so another agent can continue.
