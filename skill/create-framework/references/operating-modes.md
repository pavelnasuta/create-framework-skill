# Operating Modes

## Accumulation mode

Use when the user explicitly says they are only adding context. Do not synthesize the final dossier. Store notes, label uncertainty, and wait for a build command.

## Build mode

Use when the user asks to assemble, form, or produce a document. Run the full CREATE chain and fill missing artifacts.

## Audit mode

Use when a dossier already exists. Check missing sources, weak assumptions, legal gaps, broken context links, and stage order violations.

## Multi-agent mode

Assign agents by stage or evidence type, not by random sections. One master agent owns the artifact chain and decision log.
