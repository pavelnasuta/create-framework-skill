# T — Tuning (Настройка)

**Цель этапа:** валидировать продукт на реальных данных и найти точки роста. AI помогает анализировать данные глубоко, ускоряя итерации.

**Входные данные (обязательные):** C + A (бизнес-цели/метрики, MVP concept) + **реальные данные** из MVP (метрики воронки, отзывы).
**Артефакты этапа:** AARRR-Analysis · User Feedback Analysis · AI-Driven A/B Testing Plan

---

## Prompt T1 — AARRR-Analysis (улучшенный)

**Роль:** Ты — аналитик роста, имеющий доступ к реальным данным MVP. Находишь узкие места и гипотезы.

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **Сырые данные по воронке:** Acquisition [N] · Activation [%] · Retention [%] · Referral [%] · Revenue [%]

**Инструкция:**
1. Проанализируй каждый этап AARRR относительно целей из A2.
2. Выяви **узкие места** — где наибольший отток относительно нормы/цели.
3. Для каждого узкого места: **3–5 гипотез**, почему и как исправить. Обоснуй каждую.

**Формат выхода:** отчёт по этапам воронки + конкретные гипотезы оптимизации с приоритетом.

**Критерии качества:** гипотезы проверяемы; каждая привязана к конкретному провалу в данных.

---

## Prompt T2 — User Feedback Analysis (улучшенный)

**Роль:** Ты — исследователь CX. Анализируешь качественные данные (отзывы) и находишь скрытые инсайты.

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **Отзывы пользователей:** [ВСТАВИТЬ]
3. **Метрики продукта:** [ВСТАВИТЬ]

**Инструкция:**
1. Проанализируй отзывы и метрики.
2. Выяви боли/запросы, неочевидные на этапе R.
3. Определи, какой контент/функции дают наибольшее эмоциональное удовлетворение (связь с Emotional Problem из C).
4. Сформулируй **3–5 гипотез** улучшения.

**Формат выхода:** отчёт с выводами по отзывам + гипотезы улучшения.

---

## Prompt T3 — AI-Driven A/B Testing Plan (улучшенный)

**Роль:** Ты — экспериментатор. Запускаешь автоматизированное A/B-тестирование гипотез из T1/T2.

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **Гипотеза:** [ВСТАВИТЬ одну, напр. «Упрощение онбординга повысит конверсию активации»]

**Инструкция:**
1. **Генерация вариантов:** 3–4 варианта для проверки гипотезы.
2. **Метрики:** какие метрики ключевые для оценки каждого варианта.
3. **Сценарий тестирования:** как AI распределяет пользователей, собирает данные, анализирует, определяет победителя (статистическая значимость).

**Формат выхода:** план A/B-теста (варианты + метрики + сценарий анализа).

---

**Результат этапа T:** AI учится на реальном поведении, предлагает конкретные улучшения на основе фактов. Передавай в E: метрики (улучшенные), архетипы/боли из R, гипотезы роста.
