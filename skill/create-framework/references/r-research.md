# R — Research (Исследование)

**Цель этапа:** собрать и проанализировать данные о рынке, конкурентах и аудитории. AI — мощный аналитический инструмент для выявления неочевидных инсайтов.

**Входные данные (обязательные):** артефакты этапа C (Vision/Mission, Core Values, Emotional Problem).
**Входные данные (по ходу):** сырые данные для поиска (ключевые слова, конкуренты), данные опросов/интервью от пользователя.

**⚠️ Правило честности:** не выдумывай факты о рынке/конкурентах. Для реальных данных используй `web_search` / `web_extract` или данные, которые дал пользователь. Там, где данных нет, помечай явно: `(гипотеза, не проверено)`.

**Артефакты этапа:** Market Analysis (SWOT/PESTEL/Портер) · Competitive Analysis · User Research (Pain Points, CJM) · User Archetypes

---

## Prompt R1 — Market Research & Trend Analysis (улучшенный)

**Роль:** Ты — продуктовый аналитик, глубоко понимающий наш контекст (C). Проводишь исследование онлайна.

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ Vision, Mission, Core Values, Emotional Problem]
2. **Сырые данные для поиска:** [ВСТАВИТЬ ключевые слова, темы, названия конкурентов]

**Инструкция:**
1. Если есть доступ к поиску — проведи реальный поиск по ключевым словам на сайтах, в статьях, на форумах, в соцсетях. Зафиксируй источники.
2. Выяви и проанализируй ключевые тренды, связанные с идеей. Раздели на: растущие, угасающие, неожиданные.
3. Собери частые вопросы пользователей и болевые точки (с цитатами/ссылками, где возможно).
4. Оцени sentiment онлайн-обсуждений (позитив/негатив/нейтрально + почему).

**Формат выхода:**
- **Ключевые тренды:** список с меткой рост/спад и источником
- **Частые вопросы и боли:** список
- **Sentiment:** итоговая оценка + аргументация
- **Источники:** список ссылок

**Критерии качества:** данные верифицируемы; тренды связаны с нашей идеей; есть разделение проверенного и гипотетического.

## Prompt R2 — SWOT / PESTEL / 5 сил Портера (улучшенный)

**Роль:** Ты — стратег-аналитик. Проводишь комплексный анализ рынка и конкурентной среды.

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **Факторы (примеры/от пользователя):**
   - Политический: [ВСТАВИТЬ]
   - Экономический: [ВСТАВИТЬ]
   - Социальный: [ВСТАВИТЬ]
   - Технологический: [ВСТАВИТЬ]
   - Экологический: [ВСТАВИТЬ]
   - Правовой: [ВСТАВИТЬ]
   - Наши сильные стороны: [3–5]
   - Наши слабые стороны: [3–5]

**Инструкция:**
1. **SWOT:** Strengths/Weaknesses (внутренние), Opportunities/Threats (внешние). Для каждого пункта — почему это так.
2. **PESTEL:** по каждому фактору — ключевой тренд и риск/возможность для нас.
3. **5 сил Портера:** угроза новых игроков, сила поставщиков, сила покупателей, товары-заменители, конкуренция внутри отрасли. Оцени каждую (низкая/средняя/высокая) и обоснуй.

**Формат выхода:** SWOT-таблица · выводы PESTEL · оценка 5 сил + итоговый вердикт о привлекательности рынка.

**Критерии качества:** выводы не абстрактны; каждая сила/фактор ведёт к действию или гипотезе.

## Prompt R3 — Competitive Analysis (улучшенный)

**Роль:** Ты — аналитик конкурентов. Находишь сильные/слабые стороны конкурентов и «пробелы» (white space).

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **Конкуренты:** [ВСТАВИТЬ список: кто, их сильные/слабые стороны, что говорят отзывы]

**Инструкция:**
1. Для каждого конкурента: сильные стороны, слабые стороны (на основе сайта/отзывов/маркетинга).
2. Найди **white space** — что конкуренты упускают, и где наши Vision/Mission/Values дают преимущество.
3. Сформулируй 2–3 наших дифференциатора.

**Формат выхода:** таблица конкурент → сильные/слабые → упущенная возможность; итоговый блок «Наши преимущества».

## Prompt R4 — User Research: вопросы + Pain Points + CJM (улучшенный)

**Роль:** Ты — UX-исследователь. Готовишь инструменты исследования и анализируешь боли/CJM.

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **Эмоциональная проблема:** [ВСТАВИТЬ из C3]
3. **Данные (если есть):** ответы опросов, стенограммы интервью, поведенческие метрики

**Инструкция (часть А — если исследование ещё не проводили):**
- 10–15 вопросов для глубинного интервью + 10–15 для массового опроса + что хотим узнать + план анализа качественных данных.

**Инструкция (часть Б — анализ имеющихся данных):**
1. Выяви 3–5 ключевых болевых точек (pain points), сфокусировавшись на эмоциональной составляющей из C.
2. Построй CJM: этапы (осознание → поиск решения → планирование → использование → ...), действия, эмоции, точки оттока на каждом.

**Формат выхода:** список болей (с цитатами/примерами) · CJM (текстовая или табличная) по этапам с эмоциями.

## Prompt R5 — User Archetypes (улучшенный)

**Роль:** Ты — исследователь персон. Создаёшь многогранные портреты на основе болей и CJM.

**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **Боли + CJM:** [ВСТАВИТЬ из R4]

**Инструкция:** создай 3–4 архетипа. Каждый: имя/описание, демография, ключевые боли (как продукт их решает), мотивации/цели, эмоциональное состояние ДО и ПОСЛЕ, сценарий взаимодействия с продуктом.

**Формат выхода:** 3–4 развёрнутых карточки архетипа.

**Критерии качества:** архетипы не пересекаются; у каждого — своя эмоциональная история; они опираются на реальные боли из R4.

---

**Результат этапа R:** структурированная база о рынке и пользователе. Передавай в этап E: Pain Points, Archetypes, Emotional Problem (из C).
