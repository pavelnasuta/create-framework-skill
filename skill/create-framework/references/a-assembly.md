**Входные данные:**
1. **Контекст (C):** [ВСТАВИТЬ]
2. **MVP concept + AARRR:** [ВСТАВИТЬ из E]

**Инструкция:**
1. Сформулируй **3–5 бизнес-целей**: конкретные, измеримые, ограниченные по времени (например, «70% активации в первый месяц»).
