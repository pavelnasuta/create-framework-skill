# C — Context (Контекст)

**Цель этапа:** определить эмоциональное ядро продукта и фундаментальную идею. Сформировать ценности, которые будут руководить AI на всех следующих этапах. Это «бусина-фундамент»: без неё все последующие артефакты теряют связность.

**Артефакты этапа:** Vision & Mission · Core Values · The Emotional Problem

---

## Prompt C1 — Vision & Mission (улучшенный)

**Роль:** Ты — опытный продуктовый стратег и AI-ассистент, специализирующийся на разработке продуктов с нуля. Ты мыслишь системно, опираешься на глубинные потребности людей, а не на фичи.

**Входные данные:**
1. **Сырая идея:** [ВСТАВИТЬ — свободный текст пользователя: что, для кого, зачем]
2. **Контекст (опц.):** [ВСТАВИТЬ — домен/индустрия, регион, ограничения, если есть]

**Инструкция (шаги рассуждения):**
1. Разбери сырую идею на три слоя: (а) что физически делает продукт, (б) какую фундаментальную проблему жизни/бизнеса он решает, (в) какую трансформацию переживает пользователь до→после.
2. Сформулируй **Vision** — краткое (1 предложение), амбициозное, описывающее идеальное будущее, которое продукт помогает создать. Не про продукт, а про мир/состояние людей.
3. Сформулируй **Mission** — конкретную, в формате: «Наша миссия — [фундаментальная проблема], превратив [процесс/состояние] в [трансформацию]». Должно быть понятно: что делаем, для кого, с какой целью.
4. Проверь: Vision отвечает на «зачем мы вообще здесь», Mission — на «что конкретно делаем».

**Формат выхода:**
- **Vision:** <одно предложение>
- **Mission:** <одно предложение в заданном формате>
- **Почему это работает:** <2-3 предложения обоснования, связывающего идею и сформулировки>

**Критерии качества:**
- Vision масштабируемо (не привязано к текущему MVP) и вдохновляюще.
- Mission не содержит технических деталей реализации, а описывает ценность для человека.
- Обе формулировки — на русском, без канцелярита.

## Prompt C2 — Core Values (улучшенный)

**Роль:** Ты — продуктовый стратег, глубоко понимающий Vision & Mission. Твоя задача — перевести их в «этический кодекс» для AI и команды.

**Входные данные:**
1. **Vision & Mission:** [ВСТАВИТЬ из C1]
2. **Сырая идея:** [ВСТАВИТЬ]

**Инструкция:**
1. Проанализируй Mission & Vision: какие принципы должны руководить продуктом, чтобы он не предал свою миссию на практике.
2. Сформулируй **3–5 Core Values** — принципов, которые определяют, как AI генерирует контент, взаимодействует с пользователем и принимает решения.
3. Для каждой ценности дай: одно название + описание (что она означает для продукта) + **операционное правило** (как она меняет поведение AI/продукта, формат «если …, то …»).

**Формат выхода:**
```
- <Название ценности>: <описание>
  Операционное правило: если [ситуация], то AI/продукт [действие].
```
(повторить для каждой)

**Критерии качества:**
- Ценности не дублируют друг друга и не являются банальностями («качество», «честность» без конкретики — плохо).
- Каждая ценность имеет проверяемое поведенческое следствие.
- Они реально ограничивают и направляют генерацию (пример из оригинала: ценность «простота» → AI не даёт сложных рецептов).

## Prompt C3 — The Emotional Problem (улучшенный)

**Роль:** Ты — исследователь пользовательского опыта, погружённый в Vision, Mission и Core Values. Ты ищешь не задачу, а эмоцию за ней.

**Входные данные:**
1. **Vision / Mission:** [ВСТАВИТЬ из C1]
2. **Core Values:** [ВСТАВИТЬ из C2]
3. **Сырая идея:** [ВСТАВИТЬ]

**Инструкция:**
1. Игнорируй буквальную задачу (например, «сделать приложение для X»). Спроси себя: какую *эмоцию* пользователь пытается разрешить этим продуктом?
2. Опиши **эмоциональное состояние ДО**: что чувствует человек, когда сталкивается с проблемой (страх, стыд, подавленность, тревога, потерянность). Дай живой, конкретный образ.
3. Опиши **трансформацию**: как продукт, руководствуясь Mission и Values, превращает это состояние в позитивный опыт.
4. Сформулируй одно ёмкое предложение — «эмоциональное ядро» — которое потом будешь держать перед глазами на всех этапах.

**Формат выхода:**
- **Эмоция ДО:** <описание состояния с образом>
- **Эмоция ПОСЛЕ:** <описание желаемого состояния>
- **Эмоциональное ядро (1 строка):** <формулировка, которую можно вставить в любой следующий промпт как напоминание>

**Критерии качества:**
- Сфокусировано на человеке, а не на функции.
- Конкретно и узнаваемо (пользователь должен подумать «да, это про меня»).
- Связано с Core Values — продукт решает эмоцию именно через заявленные ценности.
